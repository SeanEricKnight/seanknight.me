# seanknight.me
Personal website for Sean Knight.

Deployed to Cloudflare from the `main` branch.

## Design direction

The umbrella personal hub, styled like a quiet literary notebook: warm paper tones, dark ink, a restrained rust accent. Not a corporate brand site, conversion funnel, SaaS landing page, or giant-hero site. Christianity, apparently. stays its own site.
